# ScholarFlow · AI 论文共读与脉络梳理平台 — 产品方案清单

**全局基线**：首页加载 ≤ 2s；单篇 20 页 PDF 处理完成 ≤ 60s；50 人同时在线协作；视觉为低调学术风，主色深墨绿 #1F3D36 + 米白 #F5F2EA，正文行高 1.8。
**硬约束**：不做通用网盘、不做聊天机器人；一级模块 7 个；所有 AI 结论必须带原文页码定位，无出处不生成；用户批注只可归档，永不自动删除。

---

### 01 文献导入

- **用户场景与痛点**：研究生每周新增数十篇 PDF，散落邮箱、课题组与硬盘，缺统一元数据，检索靠猜文件名。
- **核心功能**：① 批量上传 PDF/DOI/arXiv，自动抽取标题、作者、年份、期刊与参考文献；② 同 DOI 去重与版本合并提示；③ 解析队列显示进度与失败原因。
- **关键交互流程**：拖入文件 → 队列解析 → 元数据校对弹窗（可修正）→ 打标签归入课题 → 进入摘要队列。
- **技术实现要点**：pdf.js 取文本层，GROBID 抽参考文献；扫描件走 OCR；对象存储分片上传、断点续传。
- **可量化验收标准**：20 页 PDF 上传+解析 P95 ≤ 60s；元数据准确率 ≥ 95%（抽样 100 篇）；单批 50 份。

### 02 AI 三层摘要

- **用户场景与痛点**：摘要写得像宣传稿，读完抓不住结论；两周后只剩模糊印象，重读成本高。
- **核心功能**：① 生成一句话结论、300 字要点、结构化拆解三层摘要；② 结论可跳转原文页码并高亮；③ 摘要可编辑，保留历史版本可回滚。
- **关键交互流程**：解析完成 → 进入摘要队列 → 逐层渲染 → 点击页码溯源核对 → 保存或编辑。
- **技术实现要点**：按章节分段摘要再汇总；每条结论绑定 (page, bbox)；输出走 JSON Schema 强校验，缺页码即重生成。
- **可量化验收标准**：三层摘要完成 P95 ≤ 60s（20 页）；可溯源率 100%，页码准确率 ≥ 98%；保留版本 ≥ 10 个。

### 03 四栏沉淀卡

- **用户场景与痛点**：笔记散在 Word、PDF 批注和聊天记录里，写综述时临时翻找，无法横向对比同类研究。
- **核心功能**：① 每篇一张「问题—方法—结论—局限」四栏卡，预填 AI 草稿且可编辑；② 局限栏可关联后续论文的改进点；③ 批量导出 BibTeX/Markdown/表格。
- **关键交互流程**：打开论文 → 卡片预填 → 逐格校对（可溯源页码）→ 打标签关联课题 → 导出或加入素材池。
- **技术实现要点**：卡片 schema 固定四字段+自定义字段；格内引用存 (page, span) 锚点，原文变更标记失效；导出走服务端渲染。
- **可量化验收标准**：AI 预填覆盖率 ≥ 90%；100 张卡导出 ≤ 5s；编辑本地自动保存，断网不丢失。

### 04 脉络图

- **用户场景与痛点**：自动生成的引用图布局杂乱不可控，同类方法的论文未必互引，脉络断链。
- **核心功能**：① 基于参考文献自动生成引用有向图；② 节点可手动拖拽并锁定；③ 方法相近论文可强制连线，标注「疑似方法相似」。
- **关键交互流程**：展开脉络 → 拖拽节点锁定 → 框选两篇「强制连线」→ 填相似理由 → 虚线边带标签 → 存为个人/小组视图。
- **技术实现要点**：关系表存 ref/user 两类边；力导向布局叠加手动坐标；embedding 相似度推荐候选连线。
- **可量化验收标准**：100 节点图首屏 ≤ 1.5s；拖拽 ≥ 50fps；强制连线 100% 可撤销，删论文时关联边显式提示。

### 05 共读小组

- **用户场景与痛点**：组会讨论停在口头，段落级意见散在群里，缺席者无法还原上下文，结论无人收敛。
- **核心功能**：① 建组并指派精读篇目与截止时间；② 段落级批注与串式讨论，批注锚定句子；③ 实时协作显示在线状态与光标，支持 50 人同篇在线。
- **关键交互流程**：创建小组 → 导入篇目 → 批注并 @成员 → 讨论收敛为「待决议」→ 组长导出组会纪要。
- **技术实现要点**：CRDT（Yjs）+ WebSocket 保证并发一致；锚点失效降级为提示；权限分读写/只读两级。
- **可量化验收标准**：50 人在线时批注同步 ≤ 300ms；冲突合并零丢失；批注只可归档，永不自动删除。

### 06 个人知识库

- **用户场景与痛点**：读过的东西检索不到，写作时找不到当初那句结论，也不清楚阅读积压多少。
- **核心功能**：① 全文+批注+卡片统一检索，按标签、年份、方法、局限筛选；② 按课题聚合卡片生成综述大纲；③ 阅读统计（篇数、页数、积压）。
- **关键交互流程**：搜索 → 结果按论文/批注/卡片分栏 → 点击跳转原文并高亮 → 加入素材池 → 生成带页码引注的草稿。
- **技术实现要点**：中文分词与向量检索混合召回；引注（作者, 年份, p.x）自动生成；草稿模板可配置。
- **可量化验收标准**：10 万条记录检索 P95 ≤ 500ms；Top10 命中率 ≥ 85%；引注页码正确率 100%。

### 07 订阅与定价

- **用户场景与痛点**：课题组有共同预算但个人付费意愿低，免费版限制不明，试用即流失。
- **核心功能**：① 免费版/实验室版分层，差异为篇数、协作人数、脉络节点数；② 实验室版按席位订阅，含成员管理与用量看板；③ 用量临近上限提前提示，不静默中断。
- **关键交互流程**：注册即免费版 → 超限提示升级 → 组长邀请成员（席位可视化）→ 到期前 14 天提醒 → 到期仍可导出数据。
- **技术实现要点**：配额按组织维度服务端计数，异步扣减+日终对账；导出包为开放格式；欠费只停 AI，不动数据。
- **可量化验收标准**：配额判定 ≤ 1s；到期后数据可导出率 100%；全量导出包 ≤ 30 分钟生成。
